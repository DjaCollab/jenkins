Last update 2025-09-22
SOFTW-01398-00 - PostgreSQL 17 Installer

DESCRIPTION:
This package contains the installation scripts of PostgreSQL 17 and upgrade of a PostgreSQL 14.17 database to PostgreSQL 17.6
This package supports Windows Server 2022

CONTENT:
-PostgreSQL 17.6
-pgadmin4
-psqlodbc

KNOWN ISSUES:
n/a

PREREQUISITE:
- System reboot is needed prior running Postgres upgrade from pg14 to pg17.
- Make sure psql and PgAdmin are not running otherwise the upgrade from pg14 to pg17 will fail.

USAGE:
- Postgres installation:
  "SOFTW-01398-xx PostgreSQL 17 Installer vx.x.x.x.exe" /InstallType=PGinstall

- Postgres upgrade from pg14 to pg17:
  "SOFTW-01398-xx PostgreSQL 17 Installer vx.x.x.x.exe" /InstallType=PGupgrade

- Postgres minor version 17.x upgrade:
  "SOFTW-01398-xx PostgreSQL 17 Installer vx.x.x.x.exe" /InstallType=PGminor

- Re-install security:
  "SOFTW-01398-xx PostgreSQL 17 Installer vx.x.x.x.exe" /secure
